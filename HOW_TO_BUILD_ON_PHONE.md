
# Build APK without a computer (Phone only)

You have 2 easy ways:

### Option 1 - GitHub (Easiest, no install)
1. Create a free GitHub account on your phone (github.com)
2. Create new repository -> Upload all files from this ZIP
3. Go to Actions tab -> You will see "Build TV Browser APK" running
4. After 3-4 minutes, click the build -> Download artifact "Orbital-TV-Browser-APK"
5. You will get app-debug.apk -> Send to your TV via Send Files to TV app

### Option 2 - Build on Android phone directly
Install "AIDE" or "Spck Editor + Termux" from Play Store, open project, run gradle build.

### Install on TV
- On TV: Enable Developer Options > Allow Unknown Sources
- Use "Downloader" or "Send Files to TV" to transfer APK and install
